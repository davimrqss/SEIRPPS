# Previdência System 

preciso de um site para caixa de previdência. 
geração de guias em PDF, lançamento de folhas de pagamento, cadastro de conta, lançamento de pagamentos, poder filtrar por período (mês), poder filtrar por folha paga e não paga, poder filtrar por folha de servidor e folha de patronal. 
quero que me faça o site (claro, eu preciso ajustar tudo certinho contigo), e que me mostre quais APIs, linguagens de programação, bancos de dados que eu usaria e como usá-los.

irá ter contas para cada caixa de previdência e para cada funcionário MAIOR da caixa, por exemplo, administrador, gestor financeiro. 
o lançamento de pagamento, seria por exemplo, eu lanço uma folha de pagamento, cujo valor que precisa ser pagado da parte servidor é x e de patronal y. eu clico para lançar o pagamento na folha e irei digitar quanto foi pago, quanto foi recebido pela caixa de previdência até o momento. 
os dados vão ser nome, CPF, órgão, cargo, data de nasc, etc. as guias são geradas por exemplo, a guia da folha do mês de janeiro, porque a folha vem em PDF com todos os centros de custos, sua remuneração, base de calculo, contribuição servidor e contruibuiçao patronal, eu necessito lançar esses dados no site, para que tudo fique mais organizado, então eu lançaria no site a folha de pagamento para tal centro de custo, contendo a remuneração, o mês que se trata (com vencimento dia 20 de cada mês), a base de cálculo, o valor servidor e patronal, a alíquota, se o valor é 13° ou não.
